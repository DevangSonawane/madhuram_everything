1. Executive Summary
1.1 Purpose
This document outlines the requirements for developing a comprehensive web-based supply chain management system for Madhuram, a construction material supplier serving high-profile clients including Lodha and Hiranandani. The system will manage the complete lifecycle from project creation to billing, including material procurement, vendor management, delivery tracking, and installation verification.
1.2 Product Overview
The Madhuram SCM System is a web application designed to streamline construction material supply operations for multi-floor building projects. It manages plumbing and other construction materials supply across project generation, procurement, vendor management, delivery, installation, and billing.
1.3 Goals
* Digitize end-to-end material supply chain workflow
* Reduce manual paperwork and errors
* Enable real-time tracking of material procurement and delivery
* Facilitate vendor comparison and selection
* Automate document generation (PO, Challan, MER, etc.)
* Streamline billing process based on MIR and ITR
* Improve inventory visibility and stock management

4. Detailed Functional Requirements
Module 1: Project Management
4.1 Project Generation
Priority: P0 (Critical)
Features:
* Create new project with following details:
   * Project Name
   * Client Name (Lodha, Hiranandani, etc.)
   * Project Location
   * Number of Floors
   * Project Start Date
   * Expected Completion Date
   * Project Manager/Point of Contact
   * Total Project Value (estimated)
Work Order Creation:
* Generate Work Order number (auto-generated format: WO-YYYY-MM-###)
* Attach Work Order document (PDF upload)
* Link to specific client
* Set work order status: Draft, Pending Approval, Approved, In Progress, Completed
Client Management:
* Client Database with:
   * Client Name
   * Contact Person
   * Email & Phone
   * Address
   * GST Number
   * Payment Terms
   * Historical Projects
4.2 BOQ (Bill of Quantities) Management
Priority: P0
Features:
* Manual Entry Option:
   * Add items with: Item Code, Description, Unit, Quantity, Rate, Amount
   * Category-wise grouping (Plumbing, Electrical, etc.)
   * Floor-wise breakdown
* Import Option:
   * Upload Excel/CSV file
   * Template download option
   * Auto-validation of imported data
   * Preview before final import
* BOQ Features:
   * Edit/Update BOQ items
   * Version control (track changes)
   * Export to Excel/PDF
   * Total calculation
4.3 MAS (Material Approval Sheet)
Priority: P0
Features:
* Create MAS from BOQ items
* Add material specifications:
   * Brand
   * Model/Type
   * Technical specifications
   * Sample image upload
   * Datasheet upload
* Approval Workflow:
   * Submit MAS to client
   * Client review status: Pending, Approved, Rejected, Revision Required
   * Comments/feedback from client
   * Revision history
   * Email notification to client
   * Digital signature/approval
* Only approved MAS items proceed to PR generation

Priority: P0

   * Delivery Time (earliest/latest)

   * Payment Terms (best terms first)
